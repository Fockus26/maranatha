# D120 · Componentes · `PatternLayer`, `Reveal`, `StepTransition` y `EmptyState` sin MUI · Implementado

**Decisión:**
- **`components/ui/pattern-layer.tsx`** (reemplaza a `patternLayerSx`): `div` `absolute inset-0`, `aria-hidden`, sin clics, con el tile SVG de `PATTERN_TILE` px de fondo y el pan por `@keyframes pattern-pan` (en `globals.css`); el tile y la duración llegan por variables CSS del propio elemento (`--pattern-tile`, `--pattern-duration`, 8,4 s por defecto = la velocidad de siempre). `motion-reduce:animate-none`. El tile y `diagonalPattern` pasan a `theme/patternTile.ts` (sin MUI); `theme/patterns.ts` los reexporta y conserva `patternPan`/`patternLayerSx` para `Tithe`, `DashboardAuthShell`, `DashboardStatBand` y `TitheModal` hasta la ola 3.
- **`Reveal`:** el `useMediaQuery` de MUI se va; el `amount` de 0,1 por debajo de `sm` lo da un `useSyncExternalStore` sobre `matchMedia` con snapshot de servidor `false` (como escritorio), así no hay desajuste de hidratación; sigue `useHydratedReducedMotion`. API igual (`children`, `delay`, `y`).
- **`StepTransition`:** `Box component={motion.div}` pasa a `motion.div` con clases (`relative w-full overflow-x-clip`; el paso inactivo, `pointer-events-none absolute inset-x-0 top-0`). Mismo `inert` + `aria-hidden` en el paso oculto, alto animado y reduced-motion (D087). API igual.
- **`EmptyState`:** `div`/`p` con clases y `Button` de `components/ui/button.tsx` (`outlined`, `small` si `compact`). `icon` acepta un ícono lucide **y** uno MUI (`ComponentType<{ className?; "aria-hidden"? }>`). El `font-size` de Emotion (sin capa) le gana a `size-*` en un ícono MUI, así que el tamaño va con `!` (`size-7!`, `size-5!` si `compact`); se quita en la ola 5. Sin `sx`: `className?` (fusionado con `cn`); ningún consumidor pasa `sx`. El fondo del círculo es `bg-accent` (el `action.hover` de MUI): **`--accent` lo añade W2**; hasta que mergee, el círculo no tiene fondo.

**Por qué:** los cuatro eran los compuestos compartidos de estado/animación; migrarlos enteros deja a las zonas (olas 3–4) sin MUI para esto.
**Alternativa descartada:** animar el patrón con framer-motion (CSS no bloquea el hilo principal más que framer y no depende de hidratación); `useMediaQuery` propio con `useState`+`useEffect` (parpadea el `amount` en hidratación); duplicar `diagonalPattern` en la capa nueva (dos fuentes del mismo tile).
